# Juan Mariam Joseph — Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `portfolio`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your published website URL.

## Before publishing
Review all content and add your GitHub profile, resume file, and live project links. The email, phone number, and LinkedIn link are taken from the resumes you supplied.
